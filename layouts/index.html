Javascript String

  • Escape Character: digunakan untuk pengkodisian pada string
  • Unicode: digunakan untuk merepresentasikan karakter-karakter dari berbagai bahasa
  • Template Literals: digunakan untuk membuat string yang lebih mudah dibaca dan dikelola
  • Concatenation: digunakan untuk menggabungkan dua atau lebih string
  • length: digunakan untuk mendapatkan panjang dari sebuah string
  • typeof: digunakan untuk mengetahui tipe data dari sebuah variabel

Boolean

  • Boolean: tipe data yang hanya memiliki dua nilai, yaitu true atau false
  • thruthy: nilai yang dianggap benar dalam konteks boolean
  • falsy: nilai yang dianggap salah dalam konteks boolean

Variable

  • Variable: tempat untuk menyimpan data
  • var: digunakan untuk mendeklarasikan variabel yang dapat diubah nilainya
  • let: digunakan untuk mendeklarasikan variabel yang dapat diubah nilainya
  • const: digunakan untuk mendeklarasikan variabel yang tidak dapat diubah nilainya
  • shorthand: cara singkat untuk mendeklarasikan variabel

Pop Up

  • alert: digunakan untuk menampilkan pesan kepada pengguna
  • confirm: digunakan untuk meminta konfirmasi dari pengguna
  • prompt: digunakan untuk meminta input dari pengguna

Pengkodisian

  • if: digunakan untuk mengeksekusi blok kode jika kondisi terpenuhi
  • else: digunakan untuk mengeksekusi blok kode jika kondisi tidak terpenuhi
  • else if: digunakan untuk mengeksekusi blok kode jika kondisi sebelumnya tidak terpenuhi
  • while: digunakan untuk mengeksekusi blok kode selama kondisi terpenuhi
  • for: digunakan untuk mengeksekusi blok kode sebanyak jumlah tertentu
  • do...while: digunakan untuk mengeksekusi blok kode setidaknya sekali, kemudian terus mengeksekusi selama kondisi terpenuhi
  • switch: digunakan untuk mengeksekusi blok kode berdasarkan nilai dari sebuah variabel
